Download & run

Linux amd64

A native executable for Linux x86-64. No Java installation needed.

Get the archive + SHA256SUMS ↗ 
sha256sum --check SHA256SUMS
tar -xzf airgradient-tui-scala-*-linux-amd64.tar.gz
./airgradient-tui --demo

Run these commands in your download directory.

Run from source

JDK 25+

Have Java? Clone the repo and let Mill handle the rest.

Read the quick start ↗ 
git clone https://github.com/worxbend/airgradient-tui-scala.git
cd airgradient-tui-scala
./mill app.run --demo

Demo mode makes no network requests, reads no config, and writes no history.

Ready for your own air?

Point the app at your monitor’s hostname or IP address.

./airgradient-tui --url airgradient.local

airgradient.local is an example hostname. From source, use ./mill app.run --url HOST.
